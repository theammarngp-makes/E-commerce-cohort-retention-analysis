# Dashboard - Cohort Retention Analysis

## Overview
This module contains the finalized data visualizations and dashboard assets for the Cohort Retention Analysis project. These visual components are designed to provide stakeholders with an immediate, clear understanding of user retention trends, cohort sizes, and drop-off rates over time.

## Contents
The dashboard directory includes the following exported assets and documentation:

* **`cohort_heatmap.png`**: A visual heatmap matrix displaying the retention rates of different user cohorts over successive periods.
* **`retention_curve.png`**: A line chart visualizing the average user drop-off rate, illustrating how well users are retained after their initial acquisition. 
* **`cohort_size_trend.png`**: A visualization depicting the volume of new users acquired in each cohort over time, helping to identify growth trends.
* **`cohort.jpg`**: A supplementary visualization detailing cohort performance.
* **`dashboard_dictionary.md`**: A reference guide defining the specific metrics, calculated fields, and dimensions utilized within these dashboard visuals.

## Usage
These images can be directly imported into presentation decks (such as `Customer-Retention-Analysis.pptx`), reports, or embedded into BI tools. For a deep dive into how the underlying data was processed to create these visuals, please refer to the `python` directory (specifically `02_cohort_construction.py` and `03_eda_visualization.py`).
