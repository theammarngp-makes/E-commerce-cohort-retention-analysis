# 14. Limitations

- Dataset is historical/static (Kaggle export) - no ability to run live experiments or A/B test recommendations
- `customer_unique_id` may not perfectly capture repeat behavior if customers used multiple accounts/emails
- No marketing spend or campaign data available to attribute retention drivers
- Recent cohorts are "immature" (not enough elapsed time) - excluded or flagged in comparisons
- Seasonality effects not fully isolated from genuine retention trends
